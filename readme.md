## Overview

This is the source for the yetalittlewhile.com site. The contents of
the `docs` directory on the `main` branch will be published to github
pages. This drives our public site.

> NB: this is a public repo! Everything in it ends up in the public site, so zero reason for it to be otw.


## How to make changes:

* make a local clone of the repo and optionally create a new branch, if collaborating with others.
* run a local httpd so you can preview your work. i run `python3 -m http.server` but any server will do.
* navigate to the server, e.g. at [localhost:8000/docs/](http://localhost:8000/docs/)
* save your files and `git push` to the github origin to publish.
